# world-countries.geojson — источник

- Файл: `ne_110m_admin_0_countries.geojson` (упрощённые границы стран, 177 фич).
- Источник: Natural Earth (зеркало `nvkelso/natural-earth-vector`, папка `geojson/`).
- Лицензия: **public domain** (Natural Earth не требует атрибуции, но она приветствуется).
- Скачан: 2026-09-26. Используемое поле для раскраски: `ISO_A3`
  (`RUS` — Россия, `UKR` — Украина; Крым отдельной фичей не выделен —
  входит в полигон Украины и перекрывается нашим слоем `RU-CR` сверху).
- Не редактировать вручную: при обновлении скачать заново.
