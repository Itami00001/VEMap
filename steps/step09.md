# step09 — RegionPopup (v1.1)

> Актуализировано по tz-v1.1: в попапе — регион + его города со значениями за период.

## Файлы
frontend/src/features/map/RegionPopup.tsx
frontend/src/features/map/RegionMiniChart.tsx

## Что сделать
1. Клик по региону → попап.
2. Содержимое: name_ru региона, период (year, month), mood_index региона, ответов/статей,
   спарклайн истории (Recharts) + **список городов региона с их mood_index**.
3. Кнопка «Подробнее» → /data?region={id}.
4. Закрытие: крестик или клик по карте.
5. Если данных за период нет — «Нет данных» (города всё равно показываются с «—», если есть).

## Проверка
- Клик по Москве → попап с числами, спарклайн, город Москва.
- Клик по региону без городов данных → «Нет данных».
