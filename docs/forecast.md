# Прогноз Mood Index (MVP)

> ⛔ **СТАТУС: ЗАМОРОЖЕН (ТЗ v1.1, §13; step12/step13).**
> Прогноз зависит от формулы Mood Index v2.0 — она не утверждена.
> Ниже — историческая спецификация v1.0 (годы). После разморозки ось времени —
> периоды (year, month), минимум точек и горизонт пересматриваются.

## Вход

Исторические пары `(year, mood_index)` из публичных `mood_records` для региона или агрегата России.

## Модель

Baseline: линейная регрессия `sklearn.linear_model.LinearRegression` по индексу времени (year).

## Backtesting

Hold-out последней исторической точки: обучение на всех кроме последней, прогноз последней, метрика **MAE**.

## Недостаток данных

Если исторических точек **< 4**, возвращается `status: insufficient_data` без прогнозной линии.

## Горизонт

Параметр `horizon` (по умолчанию 3 года вперёд от последнего наблюдения).

## Агрегат России

Среднее mood_index по регионам за каждый год (явно помечено как `aggregate: mean_by_region`).

## Ограничения

Прогноз демонстрирует тренд, а не гарантированное будущее. Качество зависит от объёма и непрерывности истории.
