# step11 — Compare (v1.1)

> Актуализировано по tz-v1.1: сравниваем два **периода** (year + month), а не два года.

## Файлы
frontend/src/features/data/CompareYears.tsx
frontend/src/pages/ComparePage.tsx

## Что сделать
1. Роут /compare.
2. Два выбора периода (A, B: год + месяц), оба из /api/periods.
3. GET /api/compare?year_a=&month_a=&year_b=&month_b= → таблица городов с Δ.
4. На карте: переключатель режима «Абсолют» / «Изменение» (синий=рост, красный=падение).
5. Если города нет в одном из периодов — Δ = «—».

## Проверка
- 2024-01 vs 2025-06 (или иные существующие периоды): таблица + карта перекрашивается в режиме изменений.
