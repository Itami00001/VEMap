# Mood Index v1.0

> ⛔ **СТАТУС: ЗАМОРОЖЕН (ТЗ v1.1, §13; step05).**
> Ниже — историческая методика v1.0 (опросы). По v1.1 Mood Index считается из
> **тональности текстов газет**, шкала в БД строго 0–100 (вход 0–1/0–10
> нормализуется на входе), формула v2.0 **не утверждена**.
> Не реализовывать пересчёт до метрик и словаря от владельца данных.
> После утверждения — файл переписывается полностью.

**scoring_version:** `1.0`

## Входные данные

- Ответы респондентов (`Response.answers`) по вопросам опроса (`Question`).
- Типы вопросов MVP: `scale`, `single_choice`, `text`.

## Нормализация

| Тип | Правило v1.0 |
|-----|----------------|
| `scale` | Значение 1..5 линейно приводится к 0..100: `(value - 1) / 4 * 100` |
| `single_choice` | Каждому варианту в `options.choices` задан числовой `score` 0..100 |
| `text` | **Не участвует** в расчёте v1.0 |

## Веса

Вес вопроса берётся из `Question.weight` (по умолчанию 1.0).

## Формула

Для одного ответа:

```text
mood_answer = Σ(norm_i × weight_i) / Σ(weight_i)
```

где суммирование только по вопросам, для которых есть нормализованное значение.

Для региона и года:

```text
mood_index = среднее арифметическое mood_answer по всем ответам региона
```

## Диапазон

Итоговый `mood_index` ∈ [0, 100].

## Пропуски

- Пропущенный ответ по вопросу исключается из суммы этого ответа.
- Если у ответа не осталось ни одного валидного вопроса — ответ не участвует.

## Минимальная выборка

Расчёт для пары `(region_id, year)` выполняется только если **≥ 5** валидных ответов.
Иначе запись `MoodRecord` не создаётся.

## Версионирование

Результаты сохраняются с полем `scoring_version`. При смене методики старые записи не пересчитываются автоматически.
