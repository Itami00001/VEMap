# Зарубежные административные контуры

Источник — [Natural Earth, Admin 1 – States, Provinces](https://www.naturalearthdata.com/downloads/10m-cultural-vectors/10m-admin-1-states-provinces/), набор [v5.1.2 в репозитории Natural Earth Vector](https://github.com/nvkelso/natural-earth-vector/blob/f1890d9f152c896d250a77557a5751a93d494776/geojson/ne_10m_admin_1_states_provinces.geojson). Исходная геометрия распространяется как public domain. SHA-256 исходного GeoJSON — `22d0e3ad85eb3e27f17cabf8ba2d50e554fbc27a87796ff891d958185da62fb5`.

Границы упрощены топологически в Mapshaper 0.8.7 с параметрами `-simplify 6% keep-shapes`, выходная точность общих координат — 0,0001°. Для департамента Seine-Maritime и провинций KwaZulu-Natal и Western Cape взяты исходные контуры, чтобы после упрощения центры Гавра, Дурбана и Кейптауна оставались внутри областей. Из одного некорректного результата упрощения сохранены только валидные полигональные части. В файл включены `adm1_id` из исходного `adm1_code`, название и ограничивающая рамка `bbox`. Из набора исключены геометрии российских регионов и территории, которым посвящены отдельные слои карты.

Зарубежная область получает оценку из записей того же периода, чьи координаты входят ровно в один полигон. При нескольких оценках используется среднее, взвешенное по числу наблюдений. При отсутствии положительных весов используется обычное среднее. Город вне полигонов, например прибрежная точка Портсмута со справочными координатами VEMap, остаётся отдельным маркером. Контуры представляют современное административное деление из набора Natural Earth.
