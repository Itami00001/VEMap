# DEMO DATA

> Действует. По ТЗ v1.1 step04 не трогаем: набор остаётся опросным DEMO для
> проверки пайплайна; газетные DEMO — только после структуры БД от владельца данных.

**Статус: DEMO DATA — не реальные наблюдения.**

Набор `demo_survey.json` и `demo_responses.json` создан вручную для проверки пайплайна VEMap:

- 5 демо-опросов (2016, 2018, 2020, 2022, 2024);
- ответы по 6 регионам (RU-MOW, RU-SPE, RU-TA, RU-CR, RU-KDA, RU-NVS);
- 300 ответов (6 регионов × 50);
- расчёт Mood Index v1.0 после загрузки.

Не использовать эти цифры как статистику реального населения.
